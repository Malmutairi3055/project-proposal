  ## Connection to Assignment 1

In Assignment 1, we proposed the University Club Registration System. Our project has three main workflows: students can find clubs and apply for membership, club leaders can review and decide on membership requests, and administrators can manage club information.

For Assignment 2, we used the functional and non-functional requirements from our project proposal to create the GitHub issues. We created issues for FR-01 to FR-08, NFR-01, and NFR-03.

For Sprint 1, we selected four issues: #2 for active club listings, #3 for membership request submission, #5 for viewing membership requests, and #7 for managing the club directory. These issues are related to the three workflows we explained in Assignment 1.

## 1. Sprint Goal

The goal of Sprint 1 is to define and review the initial requirements for the University Club Registration System. The sprint focuses on active club listings, membership request submission, club leader request viewing, and club directory management.
